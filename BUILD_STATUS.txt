RESEARCH INNOVATION

Revision-Aware Evidence Routing for Technical Document RAG

Problem:
  Standard RAG systems cite outdated information when multiple document
  versions exist. Users cannot distinguish current from superseded evidence.

Solution:
  SpaceDoc implements deterministic, rule-based routing that:
  • Detects version changes and tracks document evolution
  • Routes queries through revision-aware applicability filters
  • Detects contradictions in evidence
  • Generates answers only from current/applicable versions

Implementation:
  • RevisionComparisonService: tracks changes between versions
  • ConflictDetectionService: identifies contradictions
  • EvidenceRoutingService: filters evidence by applicability
  • AnswerGenerationService: generates evidence-backed answers

Status:
  ✅ Core mechanisms implemented
  ⏳ Phase 6: Evaluate effectiveness with ground truth experiments
